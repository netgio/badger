# Make it so...

Make it so... is a tilt-steered flight through a starscape where you score points by flying into spiral galaxies and Mona's flying saucer.

## Usage

Open **Make It So** from the badge menu and tilt the badge to steer through
space: lean it left or right to turn, and tip it forwards or backwards to climb
or dive. The view slowly re-levels to however you are holding the badge.

Line up a galaxy or Mona's saucer inside the green reticle as it reaches you to
collect points: **10** for a galaxy and **25** for Mona. Your best score and
top five flight scores are saved between sessions.

Press **Menu** to pause and view the high-score table, then **Menu** or **Back**
to resume. Each time you open the app starts a new flight. A flight occupies
at most one row, updated as you collect points; equal scores from separate
flights can appear more than once. Scores are saved as they enter or improve
the table, so returning Home does not lose a qualifying score. Flights with
no points do not appear. An existing saved best score is kept as the first
historical entry when upgrading.

| Control | Action |
| --- | --- |
| Tilt | Steer through the star field |
| Up / Down / Left / Right | Steer without tilting |
| Select (hold) | Warp speed |
| Back | Re-level the tilt to the current position |
| Menu | Pause and show high scores; press Menu or Back to resume |
| Home | Return to the menu |

## Requirements

Uses the badge's built-in accelerometer. No network access or `secrets.py`
values are needed. In the simulator, use the direction buttons to steer.
